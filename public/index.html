PETUNJUK PRAKTIK

Konfigurasi yang perlu ditulis di VLANesia

Ikuti urutan sesuai level. Perintah Level 1 memakai sintaks Cisco dasar; Level 2–3 menggunakan perintah simulasi khusus VLANesia untuk membantu memahami konsep.

1
LEVEL 1 · DASAR

Membuat VLAN 10, 20, dan 30

Masuk ke mode konfigurasi, buat tiga VLAN sesuai divisi, lalu beri nama.

enable
configure terminal
vlan 10
name Manajemen
exit
vlan 20
name Keuangan
exit
vlan 30
name IT-Support
exit
2
LEVEL 1 · ACCESS PORT

Menempatkan PC ke VLAN

Untuk skenario utama, Fa0/1 dan Fa0/4 ditempatkan ke VLAN 10. Contoh port lain ditunjukkan agar pembagian tiga divisi jelas.

interface fastEthernet 0/1
switchport mode access
switchport access vlan 10
exit
interface fastEthernet 0/2
switchport mode access
switchport access vlan 20
exit
interface fastEthernet 0/3
switchport mode access
switchport access vlan 30
exit
interface fastEthernet 0/4
switchport mode access
switchport access vlan 10
exit
3
VERIFIKASI

Memeriksa dan menyimpan konfigurasi

Periksa tabel VLAN virtual, lalu simpan konfigurasi sebelum melakukan uji ping.

show vlan brief
write memory
Target Level 1: PC1 dan PC4 berada di VLAN 10 dan satu subnet sehingga ping dapat berhasil. Ping ke VLAN berbeda tetap gagal karena belum ada routing.
4
DEBUGGING

Perintah perbaikan khusus simulator

Untuk membantu latihan diagnosis, VLANesia menyediakan beberapa perintah sederhana berikut.

fix ip pc4 192.168.10.12
allow vlan 20 trunk
create subinterface vlan 20
fix gateway pc2 192.168.20.1
Catatan: empat perintah di atas adalah perintah pembelajaran khusus VLANesia, bukan sintaks Cisco IOS asli.
5
